The input consists of one or more stock prices provided as command line arguments. Each argument must be parsed as a natural number (0, 1, 2, ...). If any argument is not a valid natural number, the program must print an error message and exit without attempting computation.

The program must compute the maximum profit achievable by choosing a buy day i and a later sell day j, where j > i. Profit is defined as prices[j] - prices[i].

If it is impossible to achieve positive profit (that is, all later prices are less than or equal to earlier prices), the program must return 0.

The program must run in linear time with respect to the number of input prices. It must not use nested loops that make the computation quadratic.

The program must not modify the input list. It must use only additional constant space besides storing the parsed prices.

The output must be a single non-negative integer printed alone on a line: the maximum achievable profit or 0 if no profitable transaction is possible.

The program must not perform any buy after the sell; index order must strictly obey: buy index < sell index.

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int parse_prices(int argc, char *argv[], int *prices) {
    for (int i = 1; i < argc; i++) {
        char *end;
        long price = strtol(argv[i], &end, 10);
        if (*end != '\0' || price < 0) {
            printf("Error: '%s' is not a valid natural number.\n", argv[i]);
            return 0;
        }
        prices[i - 1] = (int)price;
    }
    return 1;
}

int max_profit(int *prices, int n) {
    if (n < 2) {
        return 0;
    }

    int min_price = prices[0];
    int max_profit = 0;

    for (int i = 1; i < n; i++) {
        if (prices[i] < min_price) {
            min_price = prices[i];
        } else {
            int profit = prices[i] - min_price;
            if (profit > max_profit) {
                max_profit = profit;
            }
        }
    }

    return max_profit;
}

int main(int argc, char *argv[]) {
    if (argc < 2) {
        printf("Error: No stock prices provided.\n");
        return 1;
    }

    int prices[argc - 1];
    if (!parse_prices(argc, argv, prices)) {
        return 1;
    }

    int profit = max_profit(prices, argc - 1);
    printf("%d\n", profit);

    return 0;
}
