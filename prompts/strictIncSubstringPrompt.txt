Write a complete C program that computes the length of the longest strictly increasing subsequence (LIS) from integers provided as command-line arguments.

Command-line arguments:
• The program must take zero or more command-line arguments after the program name.
• Each command-line argument after the program name must represent a valid integer, using the following rules:

A valid integer is a non-empty string consisting of an optional leading '+' or '-' followed by one or more decimal digits.

No other characters are permitted. Examples of valid integers: 0, 42, -7, +19, 003, -0004, +000.

Examples of invalid integers: "", "+", "-", "12a", "a12", "++1", "--5", "+-3", "3.14", " 5", "5 ".
• All arguments must be treated literally; no special interpretation of symbols or quotes is allowed.

Program behavior:
• If no command-line arguments are provided (argc == 1), the program must:

Print nothing to stdout.

Exit with return code 0.

• If any command-line argument after the program name is not a valid integer as defined above, the program must:

Print exactly the following message to stderr:
Error: invalid integer argument

Print nothing to stdout.

Exit with return code 1.

Task:
• Interpret each valid integer argument in order as an element of the input sequence.
• Compute the length of the longest strictly increasing subsequence (LIS). A subsequence is formed by deleting zero or more elements without changing the order of the remaining elements. “Strictly increasing” means each element must be greater than the previous one.

Output rules:
• On success, print exactly one line to stdout containing a single integer: the length of the LIS.
• Print nothing to stderr on success.
• Exit with return code 0 on success.

Error handling:
• Invalid integer argument:
Error: invalid integer argument
to stderr, exit code 1.
• Any unexpected error:

Print nothing to stdout or stderr.

Exit with return code 2.

Examples (exact behavior):

Example 1:
Arguments:
10 9 2 5 3 7 101 18
The LIS is [2, 3, 7, 18] or [2, 5, 7, 18] or [2, 5, 7, 101]; length = 4
Program output:
4

Example 2:
Arguments:
7 7 7 7
All elements equal, longest strictly increasing subsequence is just any single element; length = 1
Output:
1

Implementation constraints:
• Write the program in C in a single .c file.
• Parse integers exactly as specified.
• Use any correct O(n²) or O(n log n) algorithm.
• Produce no explanations, no headers, no comments, and no extra text; output only C code.
