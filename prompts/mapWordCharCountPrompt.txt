-Hashing must be implemented manually by walking the characters of the key using pointers.
-The map must maintain insertion order of first appearance. That is, when you print results, you must print keys in the order that the key first appeared in the input (not the order of the final hash table layout).
-After inserting all arguments, print each key and its numeric value. Use the format:
key value
(one pair per line; finish with a trailing newline after the final line)
-Free all allocated memory, including key strings, linked list nodes, and the insertion-order array.
-On any unexpected error such as allocation failure, print nothing to stderr, free nothing beyond what was already successfully allocated, and exit with returncode 2.
-On success, print nothing to stderr and exit with returncode 0.
