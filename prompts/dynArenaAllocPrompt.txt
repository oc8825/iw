Please implement an entire C file that takes in the following command line arguments:

An unspecified number of positive integers, each representing a requested allocation size in bytes.

Definition of a valid size argument:

A valid size is a non-empty sequence of decimal digits (0–9).

It must fit in a 32-bit signed integer (0 to 2147483647).

It must be interpreted as an integer number of bytes requested.

A requested size of 0 is allowed and means: allocate a 0-byte block (still subject to alignment rules).

All command line arguments must be interpreted literally.
No prefixes, suffixes, commas, signs, or non-digit characters are allowed.
If any argument contains a non-digit character or overflows, the program must treat it as invalid input.

The program must simulate manual memory arena allocation with strict alignment rules:

Arena specifications:

The arena must be a single global array of exactly 65536 bytes, declared outside any function.

The arena begins at byte offset 0.

A global size_t arena_offset (starting at 0) must track the next free location in the arena.

Allocation specifications:

Allocate blocks sequentially inside the arena.

Every allocated block must begin at an address aligned to 8 bytes relative to the arena start.

Alignment must be enforced manually, without calling any library that performs allocation.

For each requested size S, the allocation procedure must:

Compute the next aligned address ≥ arena_offset. Alignment rule:
aligned = ((arena_offset + 7) / 8) * 8.

Check whether aligned + S fits within 65536 bytes.

If it fits:

The block is allocated starting at aligned.

Update arena_offset to aligned + S.

Print the starting offset (as a decimal integer) of this allocated block, followed by a newline.

If it does not fit:

Print the exact text:
ERROR: out of memory
and exit with returncode 1.

Program output rules:

For each valid allocation, print only the block’s starting offset, one per line.

Do not print anything else.

Do not print separators other than newlines.

Error handling rules (strict):

If no command line arguments are provided:

Print nothing.

Exit with returncode 0.

If any argument is not a valid non-negative integer fitting in a 32-bit signed int:

Print the exact text:
ERROR: invalid size

Exit with returncode 1.

If the arena runs out of space for any allocation attempt, print:
ERROR: out of memory
and exit with returncode 1.

On unexpected errors (e.g., internal failures), do not print anything to stderr. Simply exit with returncode 2.

On success, do not print anything to stderr and exit with returncode 0.
