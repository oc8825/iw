Write a complete C program that reads all of its input through command line arguments and outputs a filtered list of natural numbers with all occurrences of a specified target number removed. The program must follow all requirements below:

Command line arguments:
• The first argument is the target natural number (denoted target).
• All subsequent arguments represent the list lst, consisting of zero or more natural numbers.
Natural numbers are defined as non-negative integers (0, 1, 2, ...).
All arguments must parse as valid natural numbers. A minus sign must cause an error.

If the program is run with only one argument (the target) and no list elements, the output must be empty (print just a newline) and exit with returncode 0.

The program must remove every element from lst that is exactly equal to target, preserving the relative order of all remaining elements.
The program must not modify any value other than removing target.

Output formatting:
• Print all remaining elements separated by a single space, ending with a newline.
• If no elements remain after removal, print just a newline.

Error handling:
• If any argument (including the target) is not a valid natural number, print "Error: invalid number" to stderr and exit with return code 1. Print nothing else.
• If any unexpected error occurs (allocation failure, etc.), print nothing to stderr and exit with return code 2.
• On success, print nothing to stderr and exit with return code 0.

Example:
Input arguments: 3 1 3 4 3 5
target = 3
lst = [1, 3, 4, 3, 5]
Removing all 3’s yields [1, 4, 5].
Output:
1 4 5

Another example:
Input arguments: 7 7 7 7
target = 7
lst = [7, 7, 7]
All elements removed; output is empty.
Output is just:
(newline only)

Your program must strictly comply with these rules and operate only on data supplied through command line arguments.
