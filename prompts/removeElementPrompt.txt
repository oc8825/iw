Write a complete C program that reads all of its input exclusively from command line arguments and outputs a filtered list of natural numbers with all occurrences of a specified target number removed. The program must implement all of the following requirements exactly.

Command line arguments:
The first command line argument (argv[1]) is the target natural number, called target.
All remaining arguments (argv[2] through argv[argc-1]) represent the list lst, which may contain zero or more natural numbers.

A natural number is defined as a non-negative integer: 0, 1, 2, ...
Every argument must parse as a valid natural number. Any invalid format must cause an error. A minus sign in any argument is invalid.

Parsing rules:
All arguments must be checked for correct parsing.
Valid inputs include strings like "0", "5", "123456".
Invalid inputs include "-1", "abc", "7.2", "+", "--5", "3x", and anything else not strictly a non-negative integer.

If parsing any argument fails:
Print exactly the following message to stderr:
Error: invalid number
Then exit immediately with return code 1.
Do not print anything else to stdout or stderr.

Behavior when only the target is provided:
If argc equals 2 (meaning there is a target but the list is empty):
Print a newline character (an empty line) to stdout.
Exit with return code 0.

Filtering requirements:
Remove every element of lst that is exactly equal to target.
Preserve the original relative order of all remaining elements.
Do not modify any values except removing those equal to target.

Output formatting on success:
If at least one element remains after filtering, print them separated by a single space, followed by a newline.
If no elements remain, print only a newline.
On success, print nothing to stderr and exit with return code 0.

Unexpected errors:
If any unexpected error occurs, such as allocation failure (even though none should be needed), print nothing to stdout or stderr and exit with return code 2.

Examples:

Example 1:
Input arguments: 3 1 3 4 3 5
target = 3
lst = [1, 3, 4, 3, 5]
After removing all occurrences of 3, the result is [1, 4, 5].
Output should be:
1 4 5
(with a newline at the end)

Example 2:
Input arguments: 7 7 7 7
target = 7
lst = [7, 7, 7]
All elements are removed, so the output is just:
(newline only)

Additional requirements:
The program must strictly follow all rules above.
The program must operate only on data supplied through command line arguments.
All outputs, formatting, error messages, and behaviors must match these specifications exactly for all valid and invalid inputs.
