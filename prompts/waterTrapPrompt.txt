Write a complete C program that reads its input entirely from the command line and computes how much water can be trapped between elevations after it rains. The program must obey the following rules exactly.

Command-line arguments and invocation:

The program takes an unspecified number of command-line arguments after the program name. Each argument must represent a non-negative integer height (0, 1, 2, ...).

If the program is invoked with no command-line arguments (argc == 1), the program must print nothing to stdout and exit with return code 0.

Parsing rules:

Each argument must parse as a valid non-negative integer in base 10 with no extra characters. Leading '+' is permitted; a leading '-' is not permitted and should be considered invalid.

Examples of valid height tokens: "0", "12", "+5", "000".

Examples of invalid tokens: "-1", "3.14", "abc", "4a".

Parsing must be performed using strict rules: after converting the token with strtol/strtoll-style parsing, there must be no trailing characters other than the string terminator.

Invalid input handling:

If any command-line argument fails validation as a non-negative integer according to the rules above, the program must:

Print exactly the following to stderr (without quotes and with a single newline):
Error: invalid height

Exit with return code 1.

Print nothing else to stdout or stderr.

Computation:

Let heights[] be the array of non-negative integers parsed from argv[1] ... argv[argc-1] in that exact order. Do not modify the input order.

Compute the total amount of water that can be trapped after raining, assuming each bar has width 1 and heights are elevations at consecutive positions.

The amount trapped at position i equals max(0, min(max_height_to_left_of_i, max_height_to_right_of_i) - heights[i]).

Sum this quantity for all positions i to obtain the final answer.

Output on success:

On success, the program must print exactly one non-negative integer (the total units of trapped water) followed by a newline to stdout.

The program must print nothing to stderr on success.

The program must exit with return code 0 on success.

Unexpected failures:

If any unexpected failure occurs (for example, an internal allocation failure), the program must print nothing to stdout or stderr and exit with return code 2.

Examples:

Example 1:
Command-line arguments:
0 1 0 2
Explanation: heights = [0,1,0,2]. Water trapped = 1 unit at index 2.
Output:
1

Example 2:
Command-line arguments:
4 2 0 3 2 5
Explanation: heights = [4,2,0,3,2,5]. Water trapped = 9 (2 + 4 + 1 + 2).
Output:
9

Implementation notes (for clarity, not enforced):

Any correct algorithm is acceptable: two-pass prefix/suffix max arrays, two-pointer linear algorithm, etc.

Do not print any debugging information.

Follow the exact error message and exit code rules above.
