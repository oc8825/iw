-For each key, compute how many characters in the deep copy are uppercase ASCII letters ('A' through 'Z'), using only pointer dereferencing.
-Store that integer in counts[i].
-Print each entry exactly as:
word uppercase_count
(one per line, ending with a trailing newline)
-Free all allocated memory.
-On unexpected error (allocation failure, etc.), print nothing to stderr and exit returncode 2.
-On success, print nothing to stderr and exit returncode 0.

Please write this code in C. Please write only the code itself, no explanations, markdown fences, or other content, as I want to be able to copy the results directly into a file and run them.
