Write a complete C program that takes its input entirely from command line arguments and swaps two elements at specified indices in an integer array, leaving all other elements unchanged. The program must adhere to all of the following requirements:

The command line arguments represent, in this exact order:
• The first argument: the integer index i (0-indexed).
• The second argument: the integer index j (0-indexed).
• All remaining arguments: the elements of the integer array (one or more integers).
Thus argc must be at least 4: two indices followed by at least one array element.

The program must parse the first argument as index i, the second as index j, and all remaining arguments as array elements. All values must parse as valid integers. The indices i and j must be non-negative.

The program must validate that both i and j are strictly less than the array length (which is argc − 3). If not, the program must print an error message and exit. It must also validate that the array elements are valid integers. Any parsing failure must produce an error and exit.

The program must perform the swap:
• The element originally at index i moves to index j.
• The element originally at index j moves to index i.
• All other elements remain unchanged.
Swapping an index with itself must leave the array unchanged.

The program must output the resulting array on one line, elements separated by a single space and with no trailing space.

The program must not read input from stdin and must not write anything except the result (or an error message, if applicable).

Example:
Input arguments: 1 3 4 9 2 7
Here i = 1, j = 3, array = [4, 9, 2, 7].
Output: 4 7 2 9

Another example:
Input arguments: 2 2 10 20 30 40
Output: 10 20 30 40

Your program must satisfy all requirements for full credit.
