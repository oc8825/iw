Please implement an entire C file that takes in the following command line arguments:
-An unspecified number of integers
The program must then:
-Print a single integer followed by a newline. This printed integer is the length of the longest consecutive sequence of integers that can be formed. A consecutive sequence is a sequence of elements in which each element is exactly 1 greater than the previous element. The elements do not have to be consecutive in the original array.

For example, with the command line input:
2 20 4 10 3 4 5
The program should print:
4
Explanation: the longest consecutive sequence is 2 3 4 5

Error handling
-If no command line arguments are provided, print 0 and exit with returncode 0.
-If any command line argument is not a valid integer, print the message: “Error: command line argument not an integer” to stderr and exit with returncode 1.
-If any other unexpected error occurs, do not print anything to stderr, and simply exit with returncode 2.
-On success, do not print anything to stderr, and exit with returncode 0.

Please write this code in C. Please write only the code itself, no explanations, markdown fences, or other content, as I want to be able to copy the results directly into a file and run them.
