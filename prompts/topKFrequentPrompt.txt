Please implement an entire C file that takes in the following command line arguments:
-The first command line argument is an integer k
-There are then an unspecified number of more integer command line arguments
The program must then:
-Determine the k most frequent integers within the remaining command line argument integers. k should NOT be included in the rest of the numbers counted for frequency
-Print these out in descending order by the frequency of that integer in the remaining command line arguments. If two integers were seen the same number of times, print these in ascending order by value of the integer itself. Write each output integer on the same line, with each one separated by a space. End with a newline.
-If k exceeds the number of unique integers, print all unique integers following the same frequency/value order

For example, with the command line input:
2 1 2 2 3 3 3
k =2, so the program should print:
3 2

On the input:
3 3 3 3 3 1 4 4 4 5 5 5 2 2
k = 3, so the program should print:
3 4 5

Error handling
-If zero or one command line arguments are provided, print nothing and exit with returncode 0.
-If any command line argument is not a valid integer, print the message: “Error: command line argument not an integer” to stderr and exit with returncode 1.
-If any other unexpected error occurs, do not print anything to stderr, and simply exit with returncode 2.
-On success, do not print anything to stderr, and exit with returncode 0.

Please write this code in C. Please write only the code itself, no explanations, markdown fences, or other content, as I want to be able to copy the results directly into a file and run them.
