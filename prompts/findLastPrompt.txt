Write a complete C program that reads its input entirely from the command line and prints the index of the last occurrence of a specified integer in a sorted array of integers. The program must satisfy all requirements below exactly.

Command line arguments:
• argv[1] is the target integer elem.
• argv[2], argv[3], …, argv[argc-1] form the array arr, which contains zero or more integers.
Thus argc may be as small as 2 (elem provided but arr is empty).

Integer parsing rules:
• Every argument (including elem) must parse as a valid base-10 integer using standard C rules for strtol.
• Leading plus or minus signs are allowed.
• No trailing non-numeric characters are allowed.
• If any argument fails integer parsing, the program must:
– Print exactly the following message to stderr:
Invalid integer
– Print nothing else to stderr or stdout.
– Exit with return code 1.
• If no command line arguments are provided, the program must:
– Print exactly the following message to stderr:
No command line arguments provided
– Print nothing else to stderr or stdout.
– Exit with return code 1.

Array properties:
• The array arr must be treated exactly as given and must not be modified or reordered.
• The program must not attempt to check whether arr is sorted; it must simply assume arr is sorted in non-decreasing order.

Required behavior:
• Determine the index (0-indexed) of the last occurrence of elem in arr.
• If elem occurs at least once, print the index of its last occurrence.
• If elem does not occur anywhere in arr, print exactly:
-1
• In all successful cases, the program must:
– Print exactly one integer followed by a single newline.
– Print nothing to stderr.
– Exit with return code 0.

Special cases:
• If argc == 2 (elem provided but arr is empty), then arr has size 0. Since elem does not occur, the correct output is:
-1

Unexpected failures:
• If any unexpected failure occurs (e.g., memory allocation error, although none should be required), the program must:
– Print nothing to stderr.
– Exit with return code 2.

Output formatting requirements:
• The program must print exactly one integer followed by one newline.
• No extra spaces, no additional text.

Examples:

Example 1:
Input arguments:
5 1 3 5 5 7
elem = 5
arr = [1, 3, 5, 5, 7]
Last occurrence of 5 is at index 3.
Output:
3

Example 2:
Input arguments:
9 1 2 3 4
elem = 9
arr = [1, 2, 3, 4]
elem does not appear.
Output:
-1

Example 3:
Input arguments:
12
arr is empty.
elem = 12 does not appear.
Output:
-1

Example 4 (invalid integer):
Input arguments:
7 1 2 x 4
The argument "x" is not a valid integer.
stderr:
Invalid integer
Return code: 1

Your program must follow all rules exactly and must compile and run correctly for all test cases.
