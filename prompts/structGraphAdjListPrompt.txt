Please implement an entire C file that takes in the following command line arguments:
-An unspecified number of arguments where each argument encodes a directed edge as u->v (both u and v are node labels: non-empty strings without - or >). Example: A->B, node1->node2.

The program must:
-Parse each u->v token
-Build a graph represented by an array (or other dynamically allocated container) of struct Node elements. Each struct Node must contain a char *label; and a dynamically allocated array of char * pointers for outgoing neighbors. Node labels must be deep-copied into allocated memory. The graph must contain one struct Node per distinct label encountered (either as source or destination). The adjacency lists must be dynamically resized as needed. Use malloc/realloc/free.
-After parsing all edges, for consistent output, sort the nodes by their label in ASCII lexicographic order. Also sort each node's adjacency list by neighbor label in ASCII order. Sorting must operate on the arrays inside struct Node or the node array.
-Print the adjacency list: one line per node in sorted node order, formatted as label: nb1 nb2 nb3 (neighbors separated by spaces). If a node has no outgoing edges, print label: followed by a newline. End output with a newline.
-Free all allocated memory.

For example, with the command line input:
A->B A->C B->C D->A
The program should print:
A: B C
B: C
C:
D: A

And it MUST do this by defining struct Node { char *label; char **neighbors; size_t ndegs; size_t cap; };, dynamically building nodes and adjacency arrays, sorting nodes and adjacency lists, printing adjacency lists, and freeing memory.

Error handling:
-If no command line arguments are provided, print nothing and exit with returncode 0.
-If any token does not contain the exact substring -> separating non-empty u and v, print "Error: invalid edge" to stderr and exit with returncode 1. Node labels may include punctuation but not whitespace.
-If any unexpected error occurs, do not print anything to stderr, and simply exit with returncode 2.
-On success, print nothing to stderr and exit with returncode 0.

Please write this code in C. Please write only the code itself, no explanations, markdown fences, or other content, as I want to be able to copy the results directly into a file and run them.
